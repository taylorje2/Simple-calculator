# 🧮 Basic Calculator by Ayyaan

A robust and user-friendly Command-Line Interface (CLI) Calculator built with Python. This tool allows you to perform calculations and save your history for future reference.

---

## ✨ Features

- **Multi-Operator Support**: Handles Addition (+), Subtraction (-), Multiplication (*), Division (/), and Exponentiation (**).
- **Expression Evaluation**: Directly evaluates complex expressions (e.g., `(10 + 5) * 2`).
- **Data Persistence**: Automatically creates and manages a `history_calculator.txt` file to store your results.
- **History Management**: View all past calculations or clear them whenever needed.
- **Error Handling**: Built-in checks to handle invalid expressions without crashing.

---

## 🚀 Getting Started

### 1. Prerequisites
Make sure you have **Python 3.x** installed. Check it by running:
`python --version`

### 2. Installation
Clone this repository or download `calculator.py`:
`git clone https://github.com`

### 3. Running the App
Run the script using:
`python calculator.py`

---

## 🛠️ How It Works

- **Perform Operation**: Enter option **1** and type your math expression (Example: `50 / 5 + 10`). Type `yes` to save the result.
- **Show History**: Option **2** displays all saved calculations.
- **Delete History**: Option **3** wipes the history file after confirmation.
- **Exit**: Option **4** closes the application.

---

## 📂 File Structure
- `calculator.py`: The main source code.
- `history_calculator.txt`: (Auto-generated) Stores your logs.
